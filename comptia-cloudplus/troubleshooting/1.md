## 🌐 **NETWORK SERVICE UNAVAILABILITY**

### 🏠 **DHCP (Dynamic Host Configuration Protocol)**
**What it does:** The **digital landlord** that hands out IP addresses to devices joining the network.  
**When it breaks:** New devices can't get an address → they're **homeless on the network** 🚫🏠  
**Feels like:** Showing up to a party but nobody gives you the address  
**Troubleshooting:** `ipconfig /release && ipconfig /renew` (Windows) or check DHCP server logs

### 📞 **DNS (Domain Name System)**  
**What it does:** The **internet's phonebook** - translates `google.com` to `172.217.164.110`  
**When it breaks:** Names don't resolve → you can type URLs but nothing loads 🚫🌐  
**Feels like:** Having someone's name but no phone number  
**Troubleshooting:** `nslookup google.com` or `dig google.com` - if no response, DNS is down

### ⏰ **NTP (Network Time Protocol)**
**What it does:** The **digital timekeeper** - keeps all systems synchronized  
**When it breaks:** Clocks drift → certificates think they're expired, logs make no sense 🕰️⚡  
**Feels like:** Everyone showing up to meetings at different times  
**Troubleshooting:** `ntpdate -q pool.ntp.org` - check time synchronization

### 🔄 **NAT (Network Address Translation)**
**What it does:** The **bouncer at the club** - lets multiple devices share one public IP  
**When it breaks:** Internal devices can't reach the internet 🚫🌍  
**Feels like:** Having backstage passes but the bouncer won't let you in  
**Troubleshooting:** Check NAT tables, router configurations

### 🌊 **HTTP Status Codes (The Vibe Checker)**
**What they are:** The **server's emotional responses** to your requests

| Status | Vibe | Translation |
|--------|------|-------------|
| **200 OK** ✅ | "We good, fam!" | Request succeeded |
| **301 Moved Permanently** 🚚 | "I've moved, catch me at my new spot" | Redirect |
| **400 Bad Request** 🤦‍♂️ | "Bruh, what are you even asking for?" | Malformed request |
| **401 Unauthorized** 🚫 | "You ain't on the list" | Authentication needed |
| **403 Forbidden** 🔒 | "You're on the list, but still can't come in" | No permissions |
| **404 Not Found** ❓ | "Never heard of them" | Resource doesn't exist |
| **500 Internal Server Error** 💥 | "My bad, I'm having a moment" | Server-side failure |
| **503 Service Unavailable** 🛑 | "We're closed for maintenance" | Server overloaded/down |

**When HTTP breaks:** The conversation between client and server gets dysfunctional 🗣️💥

## 🎯 **THE #DAB TROUBLESHOOTING FLOW**

**When network services go down:**
1. **"Can I ping it?"** → Basic connectivity check
2. **"Can I resolve the name?"** → DNS check  
3. **"Can I reach the port?"** → `telnet` or `nc` for specific services
4. **"What's the service saying?"** → Check logs, status codes
5. **"Is it just me?"** → Check from different locations/networks

### ☕ **Stellar Café Network Meltdown**
**Scene:** Customers can't load the loyalty app. Payments failing.  
**Investigation:** 
- DNS resolution working ✅
- HTTP requests returning **503 Service Unavailable** 🚨
- **Root cause:** Load balancer overwhelmed → can't handle more connections
- **Fix:** Scale up load balancer + add CDN caching
