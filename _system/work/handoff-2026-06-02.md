## Lessons learned (for training data)
- cross-file contamination is the #1 failure mode: patches can hit wrong file if context is noisy (see index.html `.meta` mistake)

- `search_files(target='files', path='.')` before patching to confirm exact filename/location
- submodule dirty state blocks deploy — present options, don’t auto-force
- visual QA after every meaningful change, then stop
