**DLP: Data Loss Prevention** 🚫📤

**What it is:** Systems designed to detect and prevent unauthorized data exfiltration

---

## **DLP OPERATIONS** ⚙️🔍

**Three States of Data:**
- **Data at Rest** 💾: In databases, file shares, cloud storage
- **Data in Motion** 🌊: Moving through network, email, web
- **Data in Use** 🖥️: Being accessed/processed by applications

**DLP protects all three states.**

---

## **HOW DLP WORKS** 🧠⚡

**Detection Methods:**
- **Content Analysis** 📝: Scanning for keywords, patterns, regex
- **Fingerprinting** 🔍: Digital fingerprints of sensitive files
- **Policy Enforcement** 📋: Rules-based blocking (e.g., "No SSNs via email")
- **Context Awareness** 🎯: Who, what, where, when data moves

---

## **DLP DEPLOYMENT POINTS** 📍

**Network DLP:** 🌐 Monitors traffic leaving the network
**Endpoint DLP:** 💻 Monitors data on user devices
**Cloud DLP:** ☁️ Protects data in cloud services

---

## **THE EXPLOIT'S PERSPECTIVE** 🕳️🔍

**Vulnerability:** DLP focused only on obvious channels
