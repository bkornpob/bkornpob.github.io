## TASK 1: REMOTE SYSTEM ENUMERATION
>>>Find live hosts and discover open ports.<<<

**Host Discovery:**
```
nmap -sn 10.10.10.0/24                    # Ping sweep
nmap -PE -PS443 -PA80 10.10.10.0/24       # TCP/UDP ping
fping -g 10.10.10.1 10.10.10.254 2>/dev/null
```

**Port Scanning:**
```
nmap -sS --top-ports 1000 -T4 target      # TCP SYN fast
nmap -sS -p- -T4 --min-rate 5000 target   # Full port scan  
nmap -sU -T4 -p 53,161,162 target         # Critical UDP
```
