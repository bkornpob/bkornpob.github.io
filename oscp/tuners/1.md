### **Domain 1: Identifying Vulnerabilities**
#### **Task 1: Remote System Enumeration**

**1. Core Reminder:**
*   Find open doors (ports) and identify what's behind them (services) without making a full connection (SYN scan).

**2. Tool & Command:**
*   **Tool:** `nmap`
*   **Command:**
    ```bash
    # Discover live hosts & top TCP ports quickly
    sudo nmap -sn -PE 10.10.10.0/24
    sudo nmap -sS --top-ports 1000 -T4 10.10.10.50

    # Full port TCP SYN scan (the bread and butter)
    sudo nmap -sS -p- -T4 --min-rate 10000 10.10.10.50

    # Service/version detection on found ports
    nmap -sV -sC -p 80,443,22,21,25 10.10.10.50

    # UDP scan for critical services (DNS, SNMP, DHCP)
    sudo nmap -sU -T4 -p 53,161,162 10.10.10.50
    ```

**3. Use Case & Scenario:**
*   **Scenario:** You have the IP `10.10.10.75`. Find all web services and their versions.
*   **Procedure:**
    1.  `sudo nmap -sS -p- -T4 --min-rate 5000 10.10.10.75`
    2.  Observe open ports. Assume 80, 443, 8080 are open.
    3.  `nmap -sV -sC -p 80,443,8080 10.10.10.75`
    4.  `-sC` will run default NSE scripts, often revealing web server type, title, and potential vulnerabilities.
