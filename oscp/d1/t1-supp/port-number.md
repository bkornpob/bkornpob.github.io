# TCP/UDP PORT NUMBERS 🚪🔢

## QUICK RULES:
- **PORTS = DOORS** 🚪
- **0-65535** (16-bits) TOTAL 🎯
- **TCP & UDP** CAN USE SAME NUMBERS 🔄

---

## CRITICAL PORTS 🎯:

**WEBS:** `80` (HTTP) 🌐, `443` (HTTPS) 🔒  
**SHELL:** `22` (SSH) 🐚  
**FILES:** `21` (FTP) 📁, `445` (SMB) 🪟  
**MAIL:** `25` (SMTP) 📧, `110` (POP3) 📫  
**DNS:** `53` (BOTH TCP/UDP) 🌐  
**NETWORK:** `161` (SNMP) 📊, `389` (LDAP) 🗃️

---

## PORT RANGES:
**0-1023** = WELL-KNOWN 👑 (root required)  
**1024-49151** = REGISTERED 📝 (common apps)  
**49152-65535** = DYNAMIC/PRIVATE 🎲 (ephemeral)

---

## REALITY CHECK:
**SAME PORT ≠ SAME SERVICE** ❌  
Port `80` could be HTTP 🌐 OR custom app 🛠️  
**ALWAYS VERIFY** ✅
