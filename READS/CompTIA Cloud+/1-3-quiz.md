---

#### **1.** A company wants to securely connect its on-premises data center to its cloud VPC over the public internet. Which solution is **most** appropriate?  
**A.** Dedicated Connection  
**B.** VPN  
**C.** VPC Peering  
**D.** CDN  

---

#### **2.** Stellar Café wants to ensure that its POS system is never directly exposed to the internet. Which VPC feature should they use?  
**A.** Public Subnet  
**B.** Private Subnet  
**C.** Internet Gateway  
**D.** NAT Gateway  

---

#### **3.** Which protocol is responsible for dynamically rerouting traffic between different cloud regions during an outage?  
**A.** OSPF  
**B.** BGP  
**C.** VLAN  
**D.** SDN  

---

#### **4.** What is the primary benefit of using a **Content Delivery Network (CDN)**?  
**A.** Encrypts data at rest  
**B.** Provides low-latency access to cached content  
**C.** Connects two VPCs privately  
**D.** Balances traffic between application tiers  

---

#### **5.** Which service would you use to distribute incoming web traffic across multiple servers in different availability zones?  
**A.** VPN  
**B.** Application Load Balancer  
**C.** VPC Peering  
**D.** Route Tables  

---

#### **6.** True or False: Using a Dedicated Connection (like AWS Direct Connect) means your traffic travels over the public internet.  
**A.** True  
**B.** False  

---

#### **7.** Which feature allows you to connect multiple VPCs together through a central hub?  
**A.** Subnet  
**B.** Transit Gateway  
**C.** NAT Gateway  
**D.** BGP  

---

#### **8.** Why would you use **SD-WAN** in a multi-branch cloud setup?  
**A.** To manually route all traffic through one location  
**B.** To dynamically choose the best path for each type of traffic  
**C.** To replace all firewalls  
**D.** To cache static content  

---

#### **9.** Which of these is **NOT** typically a use case for a VPN?  
**A.** Connecting remote employees to cloud resources  
**B.** Low-latency video streaming between data centers  
**C.** Secure dev/test environments over the internet  
**D.** Temporary hybrid cloud connections  

---

#### **10.** What is the main purpose of **Route Tables** in a VPC?  
**A.** To encrypt traffic between subnets  
**B.** To define how traffic is directed within the VPC  
**C.** To connect two VPCs together  
**D.** To cache DNS queries  

---

### ✅ **Answer Key**  

1. **B** – VPN  
2. **B** – Private Subnet  
3. **B** – BGP  
4. **B** – Provides low-latency access to cached content  
5. **B** – Application Load Balancer  
6. **B** – False  
7. **B** – Transit Gateway  
8. **B** – To dynamically choose the best path for each type of traffic  
9. **B** – Low-latency video streaming between data centers  
10. **B** – To define how traffic is directed within the VPC
