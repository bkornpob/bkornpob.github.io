	_"A company needs a relational database with minimal operational overhead. Which service model is best?"_ (Answer: PaaS - Managed SQL Database)    
- <a href="./1-2.html" target="_blank" rel="noopener noreferrer">1.2 Cloud Deployment Models</a>
	_"A solution requires on-premises deployment with need-to-know access. Which deployment model?"_ (Answer: Private Cloud)
- **1.3 Virtualization & Containers**
	_"Which technology provides lightweight isolation and portability for microservices?"_ (Answer: Containers/Docker)
- **1.4 Infrastructure & Networking**
	_"Users in South America report 'website not found' errors. Most likely cause?"_ (Answer: Regional DNS outage)    
- **1.5 Storage & Databases**
	_"Which backup feature is most critical when replicating data over untrusted networks?"_ (Answer: Encryption)
	
`2.0 deployment` ███████████████████ 19% 🚀  
- **2.1 Planning & Requirements**
	_"What should be considered when estimating cloud TCO?"_ (Answer: Licensing models + compliance requirements)    
- **2.2 Migration & Integration**
	_"Which strategy maintains existing architecture while moving to cloud?"_ (Answer: Lift-and-shift)
	
`3.0 operations` ███████████████ 17% ⚙️  
- **3.1 Monitoring & Optimization**
	_"An e-commerce site requires high availability. Best solution?"_ (Answer: Load balancing + auto-scaling)    
- **3.2 Maintenance & Automation**
	_"Which approach ensures consistent environment deployment?"_ (Answer: Infrastructure as Code)
    
`4.0 security` ███████████████████ 19% 🔒  
- **4.1 Identity & Access Management**
	_"What should be configured when using cloud-managed services?"_ (Answer: IAM policies)    
- **4.2 Data Security & Encryption**
	_"Following a ransomware attack, legal requires data preservation. This is:"_ (Answer: Retention policy)    
- **4.3 Network Security & Threats**
	_"Blocking malicious IP addresses is an example of:"_ (Answer: Remediation)

`5.0 devops` ██████ 10% ♾️  
- **5.1 CI/CD Pipelines**
	_"What do developers use to track changes during development?"_ (Answer: Code versioning)    
- **5.2 Infrastructure as Code**
	_"Which tool uses declarative configuration for cloud resources?"_ (Answer: Terraform/CloudFormation)

`6.0 troubleshooting` ██████████ 12% 🐞  
- **6.1 Performance & Connectivity**
	_"Users report high latency between availability zones. First step?"_ (Answer: Check network metrics)    
- **6.2 Deployment & Configuration**
	_"An application fails after deployment. Best approach?"_ (Answer: Rollback strategy)
