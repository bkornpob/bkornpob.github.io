# **1.5 Cloud-Native Design — Practice Quiz**
*Don't memorize. Feel the architecture.*

---

### 🧠 **Instructions**
- 10 questions. Scenario-based.
- Think: *“How would this bend, not break?”*
- Answers at the end.

---

#### **1.** Stellar Café's loyalty app keeps crashing during peak hours. The current system is a single, large application. Which cloud-native concept would **best** address this?
**A.** Archive Storage
**B.** Microservices
**C.** Cold Tier Storage
**D.** Hardware Pass-through

---

#### **2.** You want to ensure that a failure in the menu service doesn't take down the payment service. Which architecture style promotes this resilience?
**A.** Tightly Coupled
**B.** Monolithic
**C.** Loosely Coupled
**D.** Vertical Scaling

---

#### **3.** Which technology allows services to automatically find and communicate with each other in a dynamic cloud environment?
**A.** Service Discovery
**B.** Static IP Addressing
**C.** Hardware Clustering
**D.** Archive Retrieval Policies

---

#### **4.** True or False: Using a cloud-provided managed database service (like Amazon RDS) means you are still responsible for patching the underlying OS.
**A.** True
**B.** False

---

#### **5.** The Stellar Café dev team needs to process an order event by updating loyalty points, inventory, and analytics simultaneously. Which pattern should they use?
A. Serial Processing
B. Fan-out
C. Tight Coupling
D. Static Routing

---

#### **6.** What is the primary benefit of using a message queue between services?
**A.** Decreases storage costs
B. Enables asynchronous, decoupled communication
C. Increases network latency
D. Simplifies database design

---

#### **7.** Which of the following is a characteristic of a microservices architecture?
A． A single, shared database for all services
B． Services are deployed as one large application
C． Each service is focused on a specific business capability
D． Tight runtime dependencies between services

---

#### **8.** The principle of building systems with "healthy boundaries" between components is best described as:
A． Tight Coupling
B． Loosely Coupled Architecture
C． Vertical Integration
D． Hardware Affinity

---

#### **9.** The Stellar Café team is using a message queue to decouple their services. This is a classic example of which principle?

**A.** Loosely Coupled Architecture  
**B.** Fan-out Pattern  
**C.** Service Discovery  
**D.** Vertical Scaling

---

#### **10.** What is the main trade-off when adopting a microservices architecture?
A． Increased operational complexity
B． Reduced scalability
C． Higher storage latency
D． Decreased development flexibility

---

### ✅ **Answer Key**

1.  **B** – Microservices
2.  **C** – Loosely Coupled
3.  **A** – Service Discovery
4.  **B** – False
5.  **B** – Fan-out
6.  **B** – Enables asynchronous, decoupled communication
7.  **C** – Each service is focused on a specific business capability
8.  **B** – Loosely Coupled Architecture
9.  **A** – Loosely Coupled Architecture _(This tests the_ _**concept**_, not the objective number)*
10. **A** – Increased operational complexity
