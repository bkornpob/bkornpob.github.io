**Topic:** `2.4 Given a scenario, use code to deploy and configure cloud resources.`

**Purpose:**  
To automate cloud resource management using code for **consistency**, **repeatability**, **efficiency**, and **reduced human error**.

**Full List of Key Concepts (Expanded):**  
- **Infrastructure as Code (IaC)** → Define and provision infra using code (e.g., Terraform, AWS CloudFormation)  
- **Configuration as Code (CaC)** → Automate software and system configuration (e.g., Ansible, Chef)  
- **Scripting Logic** → Use scripts (Bash, Python) for automation tasks  
- **Variables** → Make code dynamic and reusable  
- **Conditionals** → Implement logic (if/else) based on parameters  
- **Operators** → Use comparison and logical operators in code  
- **Data Types** → Understand strings, integers, lists, maps, etc.  
- **Functions** → Write reusable code blocks  
- **Repeatability** → Ensure identical results with each deployment  
- **Drift Detection** → Identify and correct configuration drift  
- **Versioning** → Track changes with Git or similar  
- **Testing** → Validate code before deployment (e.g., unit tests, integration tests)  
- **Documentation** → Comment code and maintain READMEs  
- **Formats** → Use JSON or YAML for structured configurations  

**How to Get Full Grades:**  
- Demonstrate use of **both IaC and CaC** in a scenario  
- Show how **variables and conditionals** improve flexibility  
- Emphasize **idempotency**—code can be run multiple times safely  
- Mention **state management** (e.g., Terraform state files)  
- Highlight **security practices**—e.g., avoid hardcoding secrets, use environment variables or vaults  
- Integrate with **CI/CD** for automated testing and deployment
